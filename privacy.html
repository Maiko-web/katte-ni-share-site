プライバシーポリシー

制定日：2026年10月12日

「勝手にシェア」（以下「本アプリ」）における、利用者の情報の取り扱いについて説明します。

1. 本アプリが扱う情報

  • スマホ内の写真：登録した人物が写っているかを判定するために読み取ります。
  • 顔の特徴データ：登録した人物の顔を数値に変換したものです。写真そのものではありません。
  • Googleアカウントの情報：ログインに使うメールアドレスと名前です。
  • Googleドライブのファイル：本アプリが作成したフォルダとファイルだけです。

2. 情報の使い方

  • 写真の判定は、すべて利用者のスマホの中で行います。
  • 登録した人物が写っている写真だけを、利用者本人の Googleドライブにアップロードします。それ以外の写真はスマホの外に出しません。
  • 顔の特徴データは、利用者のスマホと、利用者が家族と共有する Googleドライブのフォルダにだけ保存します。

3. 開発者への送信・第三者への提供

本アプリは、開発者が運営するサーバーを使用しません。写真、顔の特徴データ、Googleアカウントの情報を、開発者が収集することはありません。また、これらの情報を第三者に販売・提供することはありません。

4. Googleのデータの取り扱い

本アプリは、Googleドライブの権限のうち、本アプリが作成したファイルだけを扱う権限（drive.file）のみを使用します。利用者のドライブにあるその他のファイルを読み取ることはできません。

本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

5. 情報の削除

  • 本アプリをアンインストールすると、スマホ内の顔の特徴データと判定の記録は削除されます。
  • Googleドライブにアップロードしたファイルは、利用者が Googleドライブ上でいつでも削除できます。
  • 本アプリによる Googleドライブへのアクセスは、Googleアカウントの「サードパーティ製のアプリとサービス」の設定からいつでも取り消せます。

6. 改定

本ポリシーを改定する場合は、このページで公開します。

7. お問い合わせ

本アプリに関するお問い合わせは、GitHub の Issues からお願いします。
